# Mind & Body — Taking Care of Mind and Body

A responsive, student-created health education website built with HTML, CSS, and JavaScript.

## Files
- `index.html` — complete website (styles and JavaScript are included).

## Run locally
1. Download or extract the project.
2. Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new public repository (for example, `mind-and-body-health`).
2. Upload `index.html` to the repository's root folder and commit the changes.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then click **Save**.
6. Wait for GitHub Pages to publish. The website URL will appear in the Pages section, usually:
   `https://YOUR-USERNAME.github.io/mind-and-body-health/`

## Important form note
The custom registration form uses browser-side required-field and email validation and displays a confirmation message. It does **not** transmit, email, or store submissions. A real registration system requires a teacher-approved backend or form-processing service. Do not collect sensitive personal or medical information.
